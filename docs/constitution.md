# Project Constitution

## 목적

- 상품 조회 → 주문 생성 → Toss Payments 결제까지 이어지는 커머스 백엔드를 구현한다.
- 기능 구현을 넘어 **인프라 구성 실습**(배포, RDS 운영 등 실제 운영 환경 구성 경험)까지를 목적으로 한다.

## 성공 기준

- 상품 조회 → 주문 생성 → 결제 승인으로 이어지는 전체 플로우가 **배포 환경에서 실제로 동작**한다.
- 위 환경에서 **주문을 받을 수 있는 상태**로 배포되어 있다. (실주문은 아님)

## 제약사항

- **운영 비용**: 월 $5 이하
- **유지보수 인원**: 1명 (본인)
